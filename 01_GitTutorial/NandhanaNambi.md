# Nandhana Nambi — Thoughts on GitHub

## Likes
-Pull requests aid in collaborative evaluation and emphasis. 
-Tasks remain organized and searchable with the use of labels and issues. 
-GitHub Actions (CI/CD) helps to detect mistakes automatically. 
-Using markdown and code diffs makes documents and reviews more enjoyable. 

## Dislikes
-The merge conflict user interface may appear intimidating at first. 
-The Large File Storage (LFS) configuration can be perplexing for new users. 
-It can be difficult to search for huge monorepos. 
-Action minutes and limits on private repositories may be challenging for students who are new to using git. 

## Questions
1. For class projects, should we utilize **Conventional Commits** or keep messages simple and short?
2. What are the best practices for organizing branches in a collaborative project?
