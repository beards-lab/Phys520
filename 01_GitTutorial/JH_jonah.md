# GitHub Reflections

## What I like about GitHub
I think it could be a very effective tool for working with others on large coding projects. I've never had to do that before, so I appreciate learning more about it.

## What I dislike about GitHub
I don't think its the most intuitive tool. It uses a lot of words, like fork or commit, that I don't automatically know what it means based on intuition alone. With practice, it likely wouldn't be too bad, but right now it's a bit difficult to navigate and learn. 

## Question
How exactly would I know when a particular project would be easier and better if I used Git? What are some things about a project that might signal that I should use it? This is an important point for me because I've never used it before, so I'm not used to it.
